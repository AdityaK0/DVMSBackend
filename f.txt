

Custom Messaging and Portfolio Showcase

Each user can receive personalized messages based on their templates. Additionally, vendors should have a dedicated **portfolio** section to showcase their products effectively.

---

Cost Optimization**

To minimize initial infrastructure costs, **Cloudinary** can be used as the cloud storage solution. It allows efficient media management without upfront storage expenses.


Service Improvement and User Experience

1. Product Update Enhancement:**
   Currently, when updating a product, there is no option to upload or replace the existing product image. This feature should be added so vendors can easily update images as part of the product update process.

2. During Product Creation
   When adding new products, a toast notification should confirm API activity. This helps prevent confusion when the request is successful but no immediate UI change is visible.
   Example: A short success or error toast can indicate whether the product was created successfully or if a required field is missing.
